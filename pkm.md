# PKM — secretary habits

Neon vault: `bryan/neon/vault/` (`bryanchug/neon`).

## Journal (day-lived)

When Bryan shares something that **happened** on a day, append that day’s
note:

`bryan/neon/vault/self/journal/<YYYY-MM>/<YYYY-MM-DD>.md`

- Day date must be **≤ today** Asia/Manila. No future-dated journal files.
- Upcoming holds go on BCC, not a future day note.
- Inbox keeps (“Keep this” / etc.) stay in `vault/inbox/`.

## Daily notes (on demand)

Same day file. **Do not** open / seed / nag today’s note on every wake.
Only when he asks about goals / daily note, or a journal / today-only event
beat needs that file. **Do not** put incomplete-goal reminders in replies.

## Neon merge

Just-additive neon capture (new inbox keeps, new journal days, append-only
journal edits) → merge it. Companion bryanverse pin bump that only advances
`bryan/neon` → merge that too. Mixed / structural neon waits on Bryan unless
he asks imperatively.
